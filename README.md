# Консольный набор утилит.

### Python-пакет с CLI, содержащий калькулятор и конвертер величин.

## Калькулятор
* Поддерживает целые и вещественные числа.
* Поддерживает операции `+`, `-`, `*`, `/`.
* Поддерживает унарные `+` и `-`.
* Игнорирует пробелы между токенами.
* Соблюдает приорит `*` и `/` над `+` и `-`.

## Конвертер
* Поддерживает группы:
длину: `mm`, `cm`, `m`, `km`;
массу: `g`, `kg`;
температуру: `c`, `f`, `k`.
* Регистр единиц не учитывается.
* Конвертация между разными группами запрещена.
* Температура ниже абсолютного нуля запрещена.

## Ошибки
* Пустое выражение.
* Некорректное число.
* Недопустимый символ.
* Пустое выражение.
* Два бинарных оператора подряд.
* Пропущенный операнд.
* Неверное числовое значение.
* Деление на ноль.
* Некорректное выражение.
* Неизвестная единица.
* Температура ниже абсолютного нуля.
* Несовместимые единицы.

CLI выводит ошибку в `stderr` и завершается с кодом `2`. Успешная команда завершается с кодом `0`.


## Установка

Создание виртуального окружения:

```bash
python -m venv .venv
```

Активация окружения:

```bash
#Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\Activate.ps1
```

Установка пакета и инструментов для проверки:

```bash
pip install -e .
pip install pytest ruff
```

## Использование

```bash
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```
Примеры:

```bash
python -m toolkit calc "5 + 7 * 2"
19
python -m toolkit convert 50 --from m --to mm
50000.0
```
